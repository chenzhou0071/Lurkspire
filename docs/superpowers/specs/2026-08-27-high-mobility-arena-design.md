# Lurkspire——3D 高机动 FFA 对战：设计文档

- 日期：2026-08-27
- 状态：已确认（brainstorming 完成，待转 implementation plan）
- 定位：求职作品集（技术成熟路线 + 玩法完整 + 美术完整 + 演示流畅）
- 名字：Lurkspire（潜伏尖塔）

## 1. 概览

Lurkspire：3D 低多边形风格化 FFA 对战游戏——4-8 人自由混战，一张精图，击杀计分。核心差异点是**高机动**——快跑、跑墙、滑铲的组合机动链，配"双枪（左黑右白交替开火）+ 武士刀（两刀/冲刺斩/格挡）"的武器系统。

- 前作继承：SignalDrift（2D 实时对战，Go 双进程 + Unity）——服务器架构（网关 + 房间 + MySQL）直接复用，改动点为"双人广播 → 4-8 人广播"与"2D 格子 → 3D 连续坐标"
- 技术关键词：3D 角色控制器、客户端移动 + 服务端验证、服务端权威命中、低多边形美术

## 2. 玩法设计

### 2.1 角色机动（"机动链"）

| 动作 | 设计 |
|---|---|
| 快跑 | 高移速（比常规射击游戏快 30-40%），跑动中可开枪 |
| 跑墙 | 贴墙跑**持续 3 秒**（沿墙方向限速）；跳到另一面墙或落地后**重新上墙刷新时长** |
| 滑铲 | 蹲下加速滑行（**速度比跑步略快**），滑铲中可开枪、可接跑墙 |
| 跳跃 | 普通高度（非核心） |
| 组合链 | 快跑 → 跑墙 → 跳 → 滑铲落地 → 出刀——连续机动形成"跑酷式对战" |

手感目标：自己玩 100 局不腻，机动链组合顺畅无卡顿。

### 2.2 武器系统（终版数值）

**双枪（左手黑 / 右手白）**：

| 输入 | 行为 |
|---|---|
| 左键 | 左右交替开火（黑→白→黑→白），4 发击杀（每发 25% 血） |
| 右键 | 充能技：10 秒充能一发，**最多存 3 发**；**必中锁头**（普通伤害=1 发），黑白交替使用（第 1 次右键白枪、第 2 次黑枪） |
| 弹药 | 有限弹匣 + 换弹 |

**武士刀**：

| 输入 | 行为 |
|---|---|
| 普通攻击 | 两刀击杀（近身，攻击范围判定）；**命中敌人格挡条 +20**（进攻回防守资源） |
| Shift | 冲刺斩（位移 + 一刀伤害） |
| 右键 | 立刀格挡：**格挡条 100，挡一枪扣 10（约 10 枪扣空），每秒恢复 5（20 秒回满）**；格挡期间前方减伤 **50%**（非无敌） |

武器平衡基准：枪 4 发 / 刀 2 刀 / 锁头必中 1 发——近身刀快、中远枪磨、锁头是稳定命中底牌。格挡条是刀的续航资源：可扛 10 枪，但 20 秒回满——"挡几枪就要收刀找空隙回条"；**砍中一刀回 20（抵两枪消耗）**——近战以战养战，龟缩挡枪没有收益。

### 2.3 对局规则（FFA）

- 4-8 人自由混战；击杀 +1 分；死亡 2 秒后随机安全点重生（**重生无敌 1 秒**）
- 结束条件：先到 20 分 或 5 分钟时限
- 结算：击杀榜 + 个人战绩（击杀/死亡/命中率）
- **靶子假人**：地图固定位置若干靶子（可击倒、计数），单人时练枪/测伤害/测试服务器

### 2.4 地图（一张精图）

- 风格：灰色墙体 + 大空地，低多边形
- 要素：跑墙路线（连续墙面）、高低差（滑铲下坡/跑墙上墙）、掩体分布、3-4 个经典交锋点
- 尺寸与具体布局：待 M1 原型手感确定后细化

## 3. 技术架构

### 3.1 服务器（复用 SignalDrift 双进程）

```
网关 gateway（登录/匹配/结算）—— 几乎不动
房间 roomd ×N —— 核心改动：
  ├─ 状态广播：双人 → 4-8 人（玩家 ×N 的位置/朝向/速度/动画状态）
  ├─ 世界模型：2D 格子 → 3D 连续坐标
  └─ 命中判定：服务端权威射线
MySQL（账号/战绩）—— 复用
```

### 3.2 同步方案（已确认 B）

**移动**：客户端移动 + 服务端验证
```
客户端自己跑（零延迟手感）→ 定时上报位置/速度
服务端校验：速度上限 + 瞬移检测（超出合法移动距离拒绝/回滚）
```

**射击**：服务端权威命中
```
客户端扣扳机 → 上报"开火"（位置+方向+武器）→ 服务端射线检测
→ 命中广播 → 伤害/击杀结算（子弹即时命中，非投射物）
```

**状态广播**：30Hz × N 玩家位置/朝向/动画状态；增量更新（变化才发）。

### 3.3 客户端（Unity 6，继承 SignalDrift 分层）

```
协议层（纯 C# 编解码，noEngineReferences）→ 连接层 → 业务层 → 表现层
```

新增：3D 角色控制器（机动链）、武器系统（双枪交替/蓄力/刀/格挡）、命中表现（特效/伤害数字）、HUD（弹匣/充能/血量/计分榜）、结算面板。

## 4. 美术管线

- 已有：双枪建模（黑/白）
- 要做：人物建模（低多边形人形 + 绑定）、动画约 12 个（跑/跳/滑铲/跑墙/出刀/冲刺斩/格挡/换弹/蓄力/受击/死亡/重生）、环境（灰墙+空地低模）
- 风格统一：低多边形 + 平色材质（风格化）
